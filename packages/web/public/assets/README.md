# 游戏素材（版权素材，不进 git）

本目录下的游戏图片素材版权属于原出版方（Feuerland Spiele / Capstone Games 及其
他权利方）。本仓库**不分发**这些素材：它们仅供本项目作者在本地进行**个人非商用**
开发/游玩使用，由 `npm run fetch-assets -w @gaia/web` 从公开来源重建。

- 基础游戏素材（扇区/研究板/板块/族板/标记/建筑棋子）：Etchelon/gaiaproject（GitHub）
- 18 族面板：boardgamers/gaia-project viewer（GitHub）
- Lost Fleet 素材：uiqoo.kr randomizer、Feuerland 官网、BGG 图库、Capstone 官网

如你并非本项目作者，请自行确认你拥有使用这些素材的权利（例如拥有正版游戏），
或删除本目录。本目录内容随时可删除，删除后运行 fetch-assets 可重建。
